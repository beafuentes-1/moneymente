# Dataset: Nemotron-Personas-El-Salvador

Sample of [nvidia/Nemotron-Personas-El-Salvador](https://huggingface.co/datasets/nvidia/Nemotron-Personas-El-Salvador) (synthetic Salvadoran personas).

- `nemotron_personas_sv_sample.csv`: random sample (seed 42) of ~133,000 rows from a 148,000-row selection, trimmed to ~95 MB to stay under GitHub's 100 MB file limit.

Columns: sex, age, area, education_level, household_type, occupation, marital_status, department, municipality, languages_spoken, career_goals_and_ambitions.
